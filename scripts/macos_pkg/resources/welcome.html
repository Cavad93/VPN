Welcome to CavadVPN

This installer will set up the CavadVPN client on your Mac.

What will be installed:

  • /Applications/CavadVPN/ — Python client library and modules
  • /usr/local/bin/cavadvpn — Command-line interface
  • LaunchAgent — Optional menubar app auto-launch entry

Requirements:

  • macOS 12 Monterey or later
  • Python 3.11 or later (from python.org or Homebrew)
