Before You Install

Python Requirement

CavadVPN requires Python 3.11 or later. If Python is not installed, the installer will abort.

Install Python via Homebrew:

brew install python@3.11

Or download from python.org.

Administrator Password

The installer requires administrator privileges to place files in /Applications and create the CLI wrapper in /usr/local/bin.

After Installation

Run the VPN from the command line:

cavadvpn --help

Your configuration will be stored at ~/.config/cavadvpn/config.yaml.
